## Sample Format

### Q1: What is the AWS Shared Responsibility Model?
**A:** AWS secures *of* the cloud (hardware, facilities, managed services).
The customer secures *in* the cloud (data, IAM, patching, security groups).

### Q2: Difference between Security Group and NACL?
| | Security Group | NACL |
|--|----------------|------|
| Level | Instance | Subnet |
| State | Stateful | Stateless |
| Rules | Allow only | Allow + Deny |
